# 🧟 Zombie Survival Text Game

A simple Python terminal-based zombie survival game built for learning programming and game logic.

---

## 🎮 About the Game

You are trapped in a zombie-infested area.  
Your goal is to survive by making the right decisions:

- ⚔️ Fight zombies
- ❤️‍🩹 Heal yourself
- 🏃‍♂️ Escape when possible

Every action has random outcomes, so no two games are the same.

---

## ✨ Features

- Turn-based combat system
- Random damage for player and zombie
- Healing system with limited healing items
- Escape mechanic with chance system
- Win/Lose conditions
- Simple and interactive terminal gameplay

---

## 🧠 Game Rules

- Player starts with **100 HP**
- Zombie starts with **200 HP**
- Damage is random every turn
- Healing items are limited and must be found
- Game ends when:
  - Player HP reaches 0 → 💀 Game Over
  - Zombie HP reaches 0 → 🏆 You Win

---

## 🎮 Controls

During the game, choose one option:


1 - Fight Zombie ⚔️
2 - Heal Yourself ❤️‍🩹
3 - Escape 🏃‍♂️
